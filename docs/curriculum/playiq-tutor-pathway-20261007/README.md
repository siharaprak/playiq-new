## Course path

The student creates one parent-approved Tutor Project in Module 0. Modules
1–8 add small, evidence-labeled, student-approved updates; Module 7 teaches
and creates the first source-aware Study Pack. Module 9 integrates and tests
the existing Tutor Project. Module 10 remains the separate assistant design
for another person. The Capstone finalizes the Tutor, then builds the student's
own Personal Assistant in a separate Project as the final major build.

No website source code, account integration, publication, or deployment is
part of this content package.
